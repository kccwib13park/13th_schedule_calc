# 2026 근무 스케줄 계산기

2026년 월별 업무 기간과 인원 조건을 바탕으로 현재 규칙에서 스케줄 작성이 가능한지 확인하는 정적 웹 계산기입니다. 별도 서버나 빌드 없이 `index.html`을 GitHub Pages에 배포할 수 있습니다.

## 로컬 검증

```powershell
npm.cmd install
npm.cmd test
npm.cmd run test:ui
npm.cmd run benchmark
```

브라우저 테스트는 Node로 정적 서버를 열고 Playwright Chromium에서 월 탐색, 인원 자동 보정, 계산 결과, 입력 오류, 키보드 포커스, 스와이프, 320px~1440px 뷰포트와 모션 감소 설정을 확인합니다. 런타임 의존성은 없습니다.

## 계산 규칙

- 월 프리셋, 기간, 공휴일은 `assets/schedule-engine.js`의 2026년 업무 규칙을 사용합니다.
- 시작일은 월요일, 종료일은 4주 또는 5주 기간의 마지막 일요일입니다.
- 월~토 최소 근무자 기본값은 4명, 일요일은 2명이며 총인원이 적을 때만 선택 가능한 범위로 보정합니다.
- 계산 불가능 결과의 부족량은 조건을 충족하지 못한 근무량의 합계이며 단위는 `인·일`입니다.
