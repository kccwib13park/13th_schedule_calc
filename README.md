# 2026 근무 스케줄 계산기

2026년 월별 근무 작성 기간과 인원 조건을 바탕으로 현재 규칙에서 스케줄 작성이 가능한지 확인하는 정적 웹 계산기입니다. 별도 서버나 빌드 없이 `index.html`을 GitHub Pages에 배포할 수 있습니다.

## 계산 범위

- 계산 기간은 월요일에 시작하고 일요일에 끝나는 4주 또는 5주의 완전한 주 단위입니다.
- 선택한 달의 달력상 1일부터 말일까지가 아니라 아래에 정한 근무 작성 기간을 사용합니다. 따라서 기간은 앞뒤 달이나 다음 해로 넘어갈 수 있습니다.
- 날짜는 `assets/schedule-engine.js`에 정의된 2026년 월 프리셋과 공휴일 목록을 기준으로 계산합니다.

| 선택 월 | 근무 작성 기간 | 주차 |
| --- | --- | ---: |
| 1월 | 2026-01-05 ~ 2026-02-01 | 4주 |
| 2월 | 2026-02-02 ~ 2026-03-01 | 4주 |
| 3월 | 2026-03-02 ~ 2026-04-05 | 5주 |
| 4월 | 2026-04-06 ~ 2026-05-03 | 4주 |
| 5월 | 2026-05-04 ~ 2026-05-31 | 4주 |
| 6월 | 2026-06-01 ~ 2026-07-05 | 5주 |
| 7월 | 2026-07-06 ~ 2026-08-02 | 4주 |
| 8월 | 2026-08-03 ~ 2026-09-06 | 5주 |
| 9월 | 2026-09-07 ~ 2026-10-04 | 4주 |
| 10월 | 2026-10-05 ~ 2026-11-01 | 4주 |
| 11월 | 2026-11-02 ~ 2026-12-06 | 5주 |
| 12월 | 2026-12-07 ~ 2027-01-03 | 4주 |

## 휴일과 주간 근무 규칙

- 모든 근무자는 월요일부터 일요일까지 매주 기본휴일을 정확히 2회 사용해야 합니다. 따라서 기본휴일은 4주 기간에 1인당 8일, 5주 기간에 1인당 10일입니다.
- 모든 근무자는 한 주에 최대 5일만 근무할 수 있으며, 월요일부터 일요일까지의 주간 총 근무시간은 52시간을 초과할 수 없습니다.
- 계산기는 일별 또는 교대별 근무시간을 입력받아 52시간을 직접 합산하지 않습니다. 현재 계산에서는 주 52시간 상한을 지키기 위한 필수 운영 조건으로 `매주 기본휴일 2회`와 `주당 최대 5근무일`을 적용합니다.
- 기본휴일은 토요일이나 일요일에 고정되지 않으며, 반드시 같은 주의 월요일부터 일요일 사이에 배치해야 합니다.
- 연속 근무일 수와 연속 휴일 수에는 별도 제한이 없습니다.
- 공휴일은 기본휴일과 별도입니다. 기본휴일 2회를 이미 사용한 주에도 공휴일을 추가로 배치할 수 있습니다.
- 1인당 기본휴일과 공휴일의 합계는 근무 작성 기간의 전체 날짜 수를 초과할 수 없습니다.

## 공휴일 적용 조건

- 공휴일은 선택한 달의 달력 범위가 아니라 실제 근무 작성 기간의 시작일부터 종료일까지를 기준으로 집계합니다.
- 토요일 또는 일요일과 겹치는 공휴일은 공휴일 수에 포함하지 않습니다.
- 대체공휴일처럼 평일에 지정된 공휴일은 공휴일 수에 포함합니다.
- 근무 작성 기간에 포함된 주중·평일 공휴일 수를 모든 근무자에게 동일하게 부여합니다.
- 각 근무자에게 부여된 공휴일은 원래 공휴일 날짜에 고정하지 않고 해당 근무 작성 기간 안의 어느 날짜로든 옮길 수 있습니다.
- 공휴일 목록은 외부 달력에서 자동으로 가져오지 않으며, `assets/schedule-engine.js`의 고정 목록을 사용합니다. 임시공휴일이나 제도 변경은 목록을 직접 갱신해야 반영됩니다.

## 최소 근무자 규칙

- 총인원은 1명 이상의 정수입니다.
- 월요일부터 토요일까지는 동일한 최소 근무자 수를 적용하고, 일요일은 별도의 최소 근무자 수를 적용합니다.
- 최소 근무자는 해당 요일에 반드시 근무해야 하는 하한이며, 실제 근무자가 최소값보다 많은 것은 허용합니다.
- 화면에서 선택할 수 있는 최소 근무자 수는 원칙적으로 1명부터 `총인원 - 1명`까지입니다. 총인원이 1명이면 1명만 선택할 수 있습니다.
- 초기값은 총인원 6명, 월~토 최소 4명, 일요일 최소 2명입니다.
- 총인원을 줄여 기존 최소 근무자 값이 선택 범위를 벗어나면 가능한 최댓값으로 자동 조정합니다.

## 가능 여부 판정

- 모든 근무자는 동일한 수의 기본휴일과 공휴일을 받는다고 가정합니다.
- 전체 휴무량은 `총인원 × (1인당 기본휴일 + 1인당 공휴일)`로 계산합니다.
- 각 날짜에 휴무를 배치할 수 있는 인원은 `총인원 - 해당 요일 최소 근무자`입니다.
- 매주 1인당 기본휴일 2회를 우선 보장하고, 공휴일은 전체 근무 작성 기간에서 이동할 수 있는 추가 휴일로 계산합니다.
- 모든 휴일을 배치하면서 매일 최소 근무자를 충족할 수 있으면 스케줄 작성 가능으로 판정합니다.
- 조건을 충족하지 못하는 경우 부족량은 부족한 근무량의 전체 합계이며 단위는 날짜 수가 아니라 `인·일`입니다. 예를 들어 하루에 2명이 부족하면 2인·일입니다.

이 계산기는 개인별 근무표를 생성하지 않습니다. 직원별 희망휴무, 연차, 출근 불가일, 직무·숙련도, 교대조, 하루 근무시간, 연속 근무 제한과 같은 개인별 조건은 판정 대상이 아닙니다.

## 로컬 검증

```powershell
npm.cmd install
npm.cmd test
npm.cmd run test:ui
npm.cmd run benchmark
```

브라우저 테스트는 Node로 정적 서버를 열고 Playwright Chromium에서 월 탐색, 인원 자동 보정, 계산 결과, 입력 오류, 키보드 포커스, 스와이프, 320px~1440px 뷰포트와 모션 감소 설정을 확인합니다. 런타임 의존성은 없습니다.
